How to use this course

  • Take the lessons in order: each one builds on the previous.
  • Try every interactive demo: change the settings and see what happens.
  • Take the quiz at the end of each lesson, and read the explanation for every option, including the wrong ones.
  • Suggested pace: Day 1 = lessons 1–2, Day 2 = lessons 3–5, Day 3 = lessons 6–7.
